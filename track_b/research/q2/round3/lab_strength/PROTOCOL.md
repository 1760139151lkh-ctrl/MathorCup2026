## 数据审计

区分名义试验温度/法向应力分组和破坏时实测温度/应力，保留原单位并显式换算为 °C、kPa。一个试验的多列测量不增加试验数；同一温度—应力组合的多试样是实验室重复，并非不同本地灾害事件。对重复编号、重复测量、缺失、异常和作者筛选分别记录，不为改善拟合删除试样。

第二份派生表的摩擦/黏聚力点用于复核两阶段作者关系及其筛选，不与原始试验再次合并成独立样本。重现作者的 ≤400 kPa 条件逐温度线性回归与 p 值筛选，并单列暖域含 800 kPa 的两阶段关系；若缓存值/打印值/文中数值不同，保留差异及原因，不强求完全一致。

## 预登记候选

响应为破坏峰值剪应力 τ；拟合使用实测法向应力 σ 和实测温度 T（若原始表仅提供其他语义，则先明确修订）。数值实现中心化/缩放不改变方程：

1. `author_eq6` 固定文献参照：τ = 53.3 − 73.5T + σ(0.42 − 0.21T)。其原域单列，域外误差只作迁移压力测试。
2. `mc_linear`：τ = a + bT + σ(c + dT)。温度线性黏聚力和摩擦，4 参数。
3. `mc_temperature_quadratic`：τ = a + bT + eT² + σ(c + dT + fT²)。温度非线性、应力线性，6 参数。
4. `mc_stress_quadratic`：τ = a + bT + σ(c + dT) + σ²(e + fT)。允许暖域应力曲率，6 参数。
5. `mc_stress_hinge_400`：τ = a + bT + σ(c + dT) + max(σ−400,0)(e + fT)。断点固定为原试验设计的 400 kPa，6 参数。留出全部 800 kPa 且缺少独立高应力支持时，若秩不足，报告不可辨识，不用伪逆冒充可验证预测。

不按本地目标应力、机械启动时刻或拟合期误差增删候选、移动断点。所有模型保留原始残差和物理诊断；无约束拟合产生负黏聚力、负摩擦或反常升温/应力响应时，报告诊断，不把数值裁剪当成数据支持。

## 分域和留出

分别报告全低应力试验域、Eq6 原温度域的低应力子集、共同暖域低应力和共同暖域全应力。共同暖域按作者名义温度组 −4 至 −0.5°C 定义；精确纳入记录由审计的分组映射绑定。

竞争主评价为共同暖域全应力数据，逐个留出完整温度组及完整应力组。全低应力域也执行这两种分组留出，报告边缘组外推与内部组插值的区别。每折训练不使用被留出试样，作者二阶段拟合点不充当额外观测。独立报告留出 800 kPa：低应力线性或二次应力系数能否由训练集辨识须检查设计秩；从 3 个低应力水平外推到第 4 个应力水平的误差不改称域内验证。

同时给出逐试样 RMSE/MAE/偏差、各留出组等权宏平均和逐温度—应力单元等权误差，防止每条件 1–6 次重复数不同改变结论。训练集 OLS 为主；单元等权拟合作为预登记权重敏感性。没有随机逐行交叉验证，不通过随机拆分同条件重复夸大跨条件泛化。

## 不确定性与可辨识性

每次拟合输出系数、设计秩/条件数、参数协方差及 HC3 稳健标准误；区间是给定本实验设计和模型的条件均值/参数不确定性，不能直接赋给本地事件概率。用固定种子、温度—应力单元内试样重采样的 1000 次分层 bootstrap 检查参数/均值敏感性，单样本单元无法识别自身方差须显式保留。若同一物理试样被多次测试，先据审计结果分块，不能当作独立重复。

bootstrap 不重采样本地事件、不生成所谓 95% 事件覆盖率；留出误差分布、预测残差和均值区间分别报告。温度/应力测量误差、批次/制样相关性及实验到现场迁移误差未由这些表完整量化，不能用内部区间替代。若候选在留出中排名不一致或出现物理反例，保留方法竞争和未知，不自动选定一个新关系。
