# 阶段 1：统一口径与验证协议草案

日期：2026-10-23。题目原有要求不变；以下默认口径供队员审视。尚无模型结果或经验覆盖率。

## 事实、建议与假设的标识

- **题面要求**：原PDF明确要求的交付；不能通过改定义省略。
- **本地事实**：可由文件、字段、脚本结果复查的内容。
- **外部证据**：官方元数据或论文；注明实际读到摘要、全文还是产品说明。
- **当前建议**：为可执行性提出的口径或验证方式，尚非队员已确认的核心建模决定。
- **待核实**：暂不可用于训练标签、标定真值或确定性结论。

## 时间与事件对象

| 字段 | 统一含义 | 使用注意 |
|---|---|---|
| `event_id` | 一次灾害链的唯一编号；同一链的多个下游点不是多个独立触发事件 | 事件表保留来源、可信级别与不确定范围 |
| `t_initiation` | 源区首次失稳/启动时刻 | 地震/滑震目录时刻与机械失稳起始可能不同，需注明代理关系 |
| `t_debris_onset` | 演变为泥石流的阶段性时刻（若可识别） | 不自动等同于` t_initiation` |
| `t_arrival(site)` | 达到目标位置的规定强度或首次可辨影响时刻 | 目标点坐标、阈值和证据必须同时定义 |
| `t_issue` | 系统发布预警或预报的时刻 | 包括数据延迟、处理耗时与发布延迟 |
| `observation_time` | 变量实际观测时刻或积分时段 | 小时标签是时段起点/末端/均值中心尚须核实 |
| `available_time` | 研究模拟发布时，该数据真正可获得的时刻 | 只能使用`available_time <= t_issue`的信息 |
| `forecast_reference_time` | 天气预报的起报时刻 | 与预报有效时间、时效lead分别保存 |
| `source_time_text` | 来源原始写法，原样保留 | 不静默用新来源覆盖旧记录 |

**建议时钟**：计算与交换保存带时区的UTC时间；论文与事件叙述显示北京时间UTC+8；涉及尼泊尔来源时显式记录UTC+5:45，转换差为2小时15分。本地CSV时间目前是无时区字符串，UTC+8的解释来自数据元信息，使用前应核实本地版本一致性。绝不把电脑时区当观测时区。

**时间分辨率**：逐小时观测不能自行支持秒级的灾前启动时刻精度。事件真值和传感器各自保留误差，不把绘图插值当新增观测。

## 空间与样本单位

| 层级 | 含义 | 建议处理 |
|---|---|---|
| R0 区域背景 | 吉隆站及周边高寒山区，站点代表区域天气环境 | 站点到灾区距离/高程差单独报告；不直接替代源区降水 |
| R1 源区 | 失稳冰岩体及其上游/邻近控制区域 | 由事件原始证据与影像核定，多边形尚待获得 |
| R2 沟道与传播域 | 源区至口岸及必要下游河道 | DEM必须全程连续覆盖；跨境源区不能被县界裁掉 |
| R3 区域易发性/泛化 | 周边流域或县域用于对照和外推 | 同一事件邻近像元不可随机拆成独立训练/测试样本 |

- 工作坐标系候选为米制投影，例如当地UTM 45N；需明确CGCS2000/WGS84转换精度要求，不能把不同CRS数值直接相叠。最终CRS、目标网格、重采样方法、垂直基准待阶段3验证后固定。
- 分类栅格与连续量采用不同重采样方案；不通过重采样声称分辨率提高。
- 历史灾点资料以文件实际几何和属性为准；“灾点”名称不保证是点几何，也不保证有事件发生时间。
- 距离可分直线距离、沿河距离和模拟到达范围；报告中必须说清采用哪一种。
- 县级人口总数不能直接转换为口岸或沿河高精度人口暴露。需要额外数据和明确下分配假设。

## Q1：关联性与TOP5

**先写清被解释量**：如果没有多事件时序标签，不以“每小时是否灾害”的未证实0/1序列训练并宣布预测成功。可以由队员选择并论证单事件的同季节背景比较、异常诊断或相似过程分析；这种证据支持关联线索，不能自动支持因果或区域通用概率。

**候选特征登记字段**：原始变量/单位、高度或深度、衍生公式、滚动窗口与滞后、物理含义、缺测要求、信息可用时间、相关变量组。边界层梯度、辐射收支、土壤水热、湍流过程仅作为待验证的特征类别；本轮不预先指定TOP5。

**排序协议建议**：在训练/探索样本确定特征和窗口；在留出样本检查方向与排序稳定性；显著性、多重比较与相关变量冗余处理由具体方法决定并记录。季节性/持续性控制和事件内序列相关必须进入验证设计。

## Q2：阈值与时空可靠性

- 临界条件可以是单变量阈值、联合条件或物理失稳界面；选型由资料、机制与可辨识性决定。
- 将“从数据估计的阈值”“文献迁移的阈值”“情景指定的阈值”分别标注；它们的证据等级不同。
- 临界值与单位、适用对象、估计样本、置信/不确定范围、误报漏报代价同时报告。
- 时间尺度建议比较若干物理合理的观测/累积窗口；空间尺度比较站点、栅格、流域聚合及分辨率变化。具体尺度待数据审计和队员选型后确定，不能事后只展示效果最佳的一种。
- 降雨阈值文献不能无条件移植到冰岩崩起始；长期变暖背景、物源失稳和短时水源触发分层讨论。

## Q3：95%区间、覆盖率与提前量

题面用“触发时间的95%置信区间”。必须在论文说明其统计对象：参数置信区间、未来事件时间预测区间、条件于已经发生事件的时间区间并非同义。建议同时尊重题面用语与实际方法名称，由队员确定方法及假设，不能把任意均值±1.96标准差直接当合格区间。

若第`i`个可核验事件真值为`t_i`、发布区间为`[L_i,U_i]`，经验覆盖率定义为：

`coverage = (1/N) * sum(1{L_i <= t_i <= U_i})`。

- 名义95%是方法目标；经验覆盖率来自独立可评估样本。单事件只能报告命中/未命中，不能证明总体校准为95%。重复同一事件的滚动窗口也不能当作N个独立事件。
- 同时报告平均/中位区间宽度、区间评分（如方法适用）、点预测误差、事件样本数和分组方法。宽到涵盖全部时段的区间没有充分实用价值。
- 对区间真值或模糊标签，应预先约定完整包含、交叠或删失似然等处理，明确分母与未评估样本，不临时改口径。
- 灾前启动提前量：`t_initiation - t_issue`；传播到达提前量：`t_arrival(site) - t_issue`。负值是迟报。二者分开统计，并包含数据/计算延迟。
- 对无预警的真实事件，计入漏报，不能从提前量分布和覆盖率中悄悄删除；误报按明确的无事件暴露时长/次数统计。
- 空间范围分别报告训练/验证适用域、预计受影响范围和到达距离；不把县界、站点邻域或栅格大小当作已验证预警半径。
- 气象预报必须保存起报时刻、有效时刻、成员/版本和当时可用性。再分析可供事后分析或明确的理想化回报试验；不能冒充历史实时预报。

## Q4：仿真证据与校准

候选层级：沟道简化传播 → 深度平均运动/水动力 → 需要更多参数的复杂模型。阶段3先做读取、范围、单位和小范围数值可行性验证，模型层级由队员选择。

参数表至少包含：地形与垂直基准、初始区域与体积/厚度、密度或组分、摩阻/流变、夹带或侵蚀、边界条件、网格/步长、求解设置及其来源/不确定性。缺失参数留空或作为情景范围，不能伪称实测。

验证分三层：数值层（稳定性、守恒、网格/步长敏感性）、物理层（合理的流深/速度/演化）、事件层（独立的到达时刻/路径/影响范围证据）。若只有文献参数或示意地形，应明确是机制或情景演示；不能声称还原实际灾害。

## 验证分组的先决条件

1. 先登记真实事件与对照，再划分样本；插补、标准化、特征筛选、阈值选择均在训练侧拟合。
2. 对有时间先后的预报任务优先时间留出/滚动评估，并设置与窗口长度匹配的隔离；不能随机打散近邻小时。
3. 对空间泛化按流域/区域留出；同一灾害链及重投影副本归同一组。
4. 数据不足时保留较弱但诚实的描述性或情景结论，同时写清无法验证的目标；不以合成样本替代真实覆盖率证据。
5. 将校准与独立验证证据分列；外部论文事后估计若用于调参，不再拿同一数字证明独立预测能力。

这些是验证设计建议，不是已经具备的标签、样本量或成功保证。方法依据和阅读范围见[调研来源](05_research_sources.md)；实际数据限制见[时序审计](03_temporal_audit.md)与[空间审计](04_spatial_audit.md)。
