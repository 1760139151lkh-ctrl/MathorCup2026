# 解析 A 适用域独立只读审查

实读冻结的 1,536,000 行首过阈导出：342 条有未来跨阈点的记录全部 `strength_domain_fraction_observed=0`，无缺失；唯一设计 p0149、唯一机制 S。linear / thaw 两政策各 171 条；assumed_latency 264、ideal 78，分布于 39 个 issue。不是 342 个独立事件，而是同一参数设计在天气、时刻和政策上的重复条件回放。

p0149：θ=51.8031645564°、法向厚度 h=59.5938415504m、ρ=2269.9135522492kg/m³。冻结定义为 `sigma_n=rho*g*h_normal*cos(theta)/1000`，g=9.80665，核算 **820.3067182465 kPa**；驱动剪应力 1042.5423767123kPa。ρ也与 `917*(1-rock_fraction)+2700*rock_fraction` 一致。S 的温度固定 -3.2690263894°C，在登记温域 [-8,-0.5]；P 恒为 0，故有效应力恒 820.3067，超过登记实验域 100–400kPa，失败原因明确是应力外推。两政策在该温度下公式相同，不能视作独立机制确认。

p0149 的八个机制/政策在 750 轨中全部域比例为 0。H 分支理论容量压力上限仅 131.2654304330kPa，即使达到容量，有效应力仍 ≥689.0412878136kPa，无法进入登记应力域；实际回放峰值压力约 2.16kPa。因此，本设计的“始终应力超域”可由静态参数与容量上界证明，无需重跑物理。

字段语义以源码为准。Q2 `strength_domain_fraction` 是完整 2089 个历史状态样本平均，包含首次越阈后的反事实延续，非仅 Aug19 后评价段。Q3 `strength_domain_fraction_observed` 是实际 L 小时随访的 **L+1** 个 issue 至终点状态的布尔标记平均，也包含跨阈后延续；拒绝天气时 L=0，比例只说明 issue 单个状态。标记检查模型界面温度及**未裁剪的有效法向应力**，不是总法向应力、触发瞬间标记、概率或观测验证分数。

S/S_H 固定初始界面温度；S/S_T 将压力置零；S_T/S_T_H 消费解析温度，H 分支压力来自条件储水状态。两种强度政策使用同一 Mamot 标记；thawed_rock_contact 在 -0.5°C 以上的替代摩擦分支仍会标为域外。该标记只涉及登记温度/应力范围，不能代替冰填石灰岩材料、快剪率、几何混合和损伤律等完整适用性审查。

廉价过滤建议，供主参谋另建增量结果：

1. **静态必要条件**可在已交付参数上检查，不看未来：无 H 分支要求 sigma_n∈[100,400]；H 分支的可达有效应力区间 `[sigma_n-Pcap,sigma_n]` 必须与 [100,400] 相交，`Pcap=g*min(connected_depth,.98*sigma_n/g)`。这能安全排除 p0149 全部分支，属于必要条件，不能声称剩余分支全程可用。
2. **已有导出的保守全样本过滤**可取 Q2 历史比例=1 与对应轨 Q3 比例=1，并同时保留风险/随访/缺测门禁；后者保证导出样本均在温应力域。比例=0 能确认全部采样点域外；0<比例<1 无法定位跨阈前括区的有效性。全轨过滤可能因跨阈后的域外延续而排除本来有有效前括区的启动，因此应标为保守过滤。有限样本域内也不是连续时间保证。
3. Q2 全历史域比例与 Q3 未来轨域比例均依赖 issue 之后的模型状态。用它们进行过滤是 **事后条件敏感性子集**，不能伪装成发布时刻可操作的先验筛选，也不能把全历史原气象下的域内当作新 GFS 情景域内证明。
4. 先保留原冻结结果，再在每个相同 issue/机制/政策/天气/时窗下对明示先验重新归一，报告剩余物理设计、剩余先验质量、风险质量、未知未来质量及事件支持。不要只删不合格的事件而保留原分母。新的机制等权策略与旧组权重条件化不一定相同，须显式选择。
5. 去除唯一事件支撑后，条件启动分位区间应为空，不能保留零宽 95% 区间。只有剩余风险质量>0、H 随访完整、未知质量为 0，才可报告该过滤条件下的情景概率 0；否则给概率界/未知，分母为 0 时保持未定义。该结果不证明真实源区不会启动、预测安全或已有实证覆盖。

本审查仅读取冻结输出和源码、核对静态代数与单位，没有调用 simulate、传热、预报或重权函数，没有改写冻结包。实际统计与输入 SHA 见 `applicability_review.json`；复核脚本 `read_only_review.py` 仅向本 review 目录新增一次审查记录。
