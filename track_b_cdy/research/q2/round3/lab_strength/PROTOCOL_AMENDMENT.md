# 拟合前审计修订

本修订基于完整原表结构和正文方法阅读，在任何竞争拟合/留出结果生成前登记；不基于本地事件、特定目标应力或候选模型表现。

1. **分组与连续变量分开。** 所有域和留出组由名义温度/应力 class 定义；模型自变量用破坏时实测 T 和 σ。400 kPa class 的实测应力可能略大于 400，−0.5°C class 的实测温度可能暖于 −0.5；不因此删除既定实验组。额外逐样本记录与文献连续适用域的越界。
2. **重复身份保留歧义。** 表有 spec1–spec8 八个标签，141 个 `(experiment_id, specimen_label)` 唯一；正文称七对岩柱、试验序列保持原配对。标签是否跨序列对应同一物理岩对缺少全局 UID，spec8 与“七对”也无法完全核对。不能声称 141 个独立物理试件，亦不能声称已证八个独立岩对。
3. **相关性敏感性。** 原协议单元内重采样 1000 次保留，明确其“不同条件试验独立”的条件假设。再做 1000 次整标签簇 pairs bootstrap、标签簇 CR1 协方差和整标签留出。标签代表同一重复岩对仅为保守敏感性；报告实际簇数、秩不足次数、有限可用次数，不承诺小簇 95% 覆盖率。HC3 作为逐行独立的计算基准，不能据此消除重复相关性。
4. **作者重现与新拟合分开。** 作者两阶段关系先按显著温度层筛选，并有逆方差/逆标准误平方权重措辞歧义；对原试验逐温层重建及派生表值分别输出。作者 Eq6 温层筛选与含 800 暖域筛选不是同一集合。报告明确 OLS、按温层回归系数 SE 的 WLS，以及按实测温度离散的 WLS，不能把一种重现实现写成唯一作者算法。
5. **固定模型竞争保持不变。** 五个参照/候选和 400 kPa 设计断点不变；共同暖域整组留出是主评价，全低应力域与 Eq6 温域用于外推/一致性对照。无任何后验增删模型或调整分组。
