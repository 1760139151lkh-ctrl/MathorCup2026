# 已测试调用域与调用方校验

本说明补充已冻结解析包，不改其21个成员。解析wrapper SHA256为`a113d3f47e97266761fa47b7d6ed7e5a9e830edeeaf2ba3918a70db3c0003607`。

- 本轮生产调用为有限正数`dt_hours=1.0`。调用方必须先检查`isfinite(dt_hours) and dt_hours>0`；当前低层核函数没有完整拒绝NaN/Inf时间步，未测试的非有限输入不属于支持域，不能依赖其输出。
- 气温为非空一维有限数组；初温、站源偏移、正扩散率和非负深度使用同一长度参数数组。生产范围为深度0.5–20m、扩散率0.9–2.1e−6m²/s；外推需要重新检查。
- `thermal_transfer_analytic`返回的是`(state_interface_temperature, interval_surface_boundary)`。状态时刻k尚未使用边界B[k]，只受B[0..k−1]影响。实际深度大于0；若深度为0，state[k≥1]取B[k−1]左极限，state0保留指定初值。
- 40m有限域与半无限域温差上界适用于已声明的一维线性导热、给定初温和分段定温边界，不是现场温差置信界。真实热对流、裂隙热通道、相变潜热和站源边界误差仍未约束。
- 热模块避免空间离散误差，但水压、损伤和强度反馈仍采用原引擎1h状态步长。FFT约1e−15°C的工程基准误差不表示源区温度可达到相应测量精度。

独立技术审查结果另见父窗口维护的`results/analytic_thermal_independent_review.json`（34项通过）；本说明只陈述已测试域与非阻塞API限制。
