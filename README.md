# 2026 MathorCup 大数据竞赛

队伍共享的比赛资料与协作仓库，包含 A、B 两个赛道的初赛赛题、完整附件、比赛规范和提交模板。280 个原始资料文件均保留原文件名与内容。

## 阅读顺序

1. 先读 [比赛规范](01_比赛规范/)，包括人工智能工具使用规定、论文格式及提交规范。
2. 查看 [提交模板](02_提交模板/)，包括论文模板和需要签名的承诺书。
3. 按选定赛道阅读赛题，再查看对应附件。
4. 完整文件归属、A 赛道附件说明和原始资料的 SHA-256 记录见 [资料索引](00_资料索引.txt)。

## B 赛道研究工作区

当前 B 赛道完整研究与论文工程位于 [track_b_cdy/](track_b_cdy/)。直接阅读[中文论文初稿](track_b_cdy/paper/output/赛道B论文初稿.pdf)、[AI工具使用详情说明](track_b_cdy/paper/output/AI工具使用详情说明.pdf)和[LaTeX源码包](track_b_cdy/paper/output/赛道B_LaTeX工程.zip)。研究、程序、数据来源与结果索引集中于该目录；原始赛题附件位于 `04_B赛道/`。

## 队友参与

克隆仓库：

```bash
git clone https://github.com/1760139151lkh-ctrl/MathorCup2026.git
cd MathorCup2026
```

在个人分支上进行分析、建模与写作，通过 Pull Request 合并到 `main`。引用数据时使用仓库中的相对路径；原始资料保持原样，处理后的数据、模型结果和论文另存为新文件。

仓库为公开仓库，任何人都可以查看和克隆。需要直接推送分支的队友，由仓库所有者通过 GitHub 的 **Settings → Collaborators → Add people** 邀请。

使用人工智能辅助比赛前，请阅读并遵守比赛提供的人工智能工具使用规定。
